# Law & Order Hauling invoice page

A simple phone-friendly page for Law & Order Hauling LLC to create invoices for Jiffy Junk.

- Live page: https://adamcjj.github.io/law-order-invoice/
- Fill in the job, check the invoice, then tap "Open email with invoice filled in". The email goes to ap@jiffyjunk.com and nothing is sent until the vendor presses Send.
- To change details (phone, PayPal email, billing address), edit `index.html` and commit. The live page updates in about a minute.
